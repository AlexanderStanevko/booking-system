
# Meeting Room Reservation System

## Project Structure

- `frontend/` — React application
- `backend/` — ASP.NET Core API

## Tech Stack

**Frontend**
- React
- TypeScript
- Vite
- Material UI
- React Router
- TanStack Query

**Backend**
- ASP.NET Core (.NET 10)
- Entity Framework Core InMemory

## Requirements

- Node.js 24 LTS
- npm
- .NET 10 SDK

## Getting Started

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

Separate terminal:

```bash
cd backend
dotnet restore
dotnet run
```
